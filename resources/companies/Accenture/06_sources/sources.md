## Source Handling Notes

The KIIT notification is the primary source for this specific 2026 KIIT recruitment drive because it directly concerns the 2027 graduating batch.

Generic Accenture recruitment information is treated as supplementary and is not used to overwrite KIIT-specific information.

The following details are deliberately not guessed:
- Exact question count
- Section-wise question count
- Negative marking
- Coding language
- Assessment duration for the KIIT drive
- Interview round types/count
- Exact mapping of the three CTC packages to the three profiles

The project notes mention approximately ₹4.x LPA, ₹6.x LPA and ₹12 LPA packages, but the supplied notification text does not establish which package belongs to which profile. Exact figures should be added only after the Superset/KIIT source showing the mapping is available.
