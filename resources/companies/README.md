# Company Resources — Sanya

This directory contains **every company folder present in the supplied `sanya.zip`**.

## Companies included

1. Accenture
2. Cognizant
3. Deloitte
4. HighRadius (HRC)
5. IBM
6. TCS
7. Tech Mahindra

Each company follows the same seven-folder structure:

- `01_company_profile/`
- `02_eligibility/`
- `03_selection_process/`
- `04_recruitment_documents/`
- `05_exam_pattern/`
- `06_sources/`
- `07_notes/`

## Organization rules

- All supplied PDFs are preserved under `04_recruitment_documents/`.
- Supplied `company_info.md` files are preserved without rewriting under `07_notes/` as consolidated research.
- Supplied `sources.md` files are preserved under `06_sources/`.
- Category folders contain a README when no separately organized source material was supplied. Such gaps are marked pending rather than filled with guessed information.
- Company-specific content and original filenames are retained.

## Important scope note

A PDF being present does not automatically mean that every eligibility, selection-process, or exam-pattern detail has been verified. Review the actual document and add a traceable source before treating a detail as confirmed.
